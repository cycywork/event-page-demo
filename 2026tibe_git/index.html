活動辦法：

  1. 電子書優惠
    1. 購買儲值點書方案回饋
      • 2026/2/2-2/9 購買500元以上的儲值方案，直接回饋10%紅利點(效期90天)， 紅利點由系統直接發送，儲值退款按 「HyRead儲值點數消費須知」辦理。
    2. 全館3本75折
      • 2026/2/10-2/12 全館購書透過「網頁」購物車結帳即可享任選3本75折，結帳依購物車實際顯示金額為準。
      • 套書結帳、部分書籍、購買儲值點數、租書、嗨讀訂閱、App或Gaze閱讀器購買不參與此活動。
    3. 春節刮刮樂
      • 2026/2/13-2/22 每個書店帳號每日可抽獎乙次，有機會獲得1、3、8、88紅利點數。
      • 紅利點數抽到後即可使用，限抽獎當日使用完畢，未使用視同放棄，不可累積。
      • 參與刮刮樂活動達7天之書店帳號，活動結束經統計後將於3/6 10:00後陸續匯入120元折價券，購書滿200可折，效期至3/12。
      • 紅利點數可至會員中心 > 點數使用紀錄中查詢。
    4. 儲值點數購書回饋
      • 2026/2/13-2/22 全館使用HyRead儲值點數購書(折價券、紅利點數不列入統計)，不限金額再回饋5%紅利點。
      • 回饋紅利點效期7天，將於2/26 10:00後陸續匯入購書書店帳號。
      • 紅利點回饋以單筆交易計算，小數點四捨五入至整數，若不足1點則無法回饋。
      • 範例說明：
        • 小明於2/13購書一筆，結帳使用1000儲值點+50紅利點，則小明將獲得1000x0.05=50紅利點。
        • 小花於2/14購書一筆，結帳刷卡1000元+50儲值點，則小花將獲得50x0.05=3紅利點。
        • 小華於2/22購書兩筆，一筆使用了8儲值點，一筆使用了9儲值點，因8x0.05=0.4、9x0.05=0.45，兩筆四捨五入後皆不足1點無法回饋。
      • 購買儲值點數、租書、嗨讀訂閱，以及購買Gaze閱讀器等實體商品不列入活動統計。
    5. 購書滿千抽
      • 2026/2/23-2/28購書結帳金額滿1000元即可符合抽「羅技簡報筆-鐵灰色」、「Raymii抱枕閱讀架-橘色」的抽獎資格。
      • 活動統計以「單筆交易」計算，一筆訂單限一次抽獎機會，不同訂單恕無法合併達成抽獎門檻，折價券、紅利點數折抵不列入活動統計。
      • 得獎名單將於3/6公布於活動網頁，並依據會員資料email通知得獎者，得獎者需於3/22前回覆，逾期視同放棄得獎資格。
      • 購買儲值點數、租書、嗨讀訂閱，以及購買Gaze閱讀器等實體商品不列入活動統計。

      • 折價券恕不補發，亦不得折換現金或找零。
